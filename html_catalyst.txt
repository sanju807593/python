what is html

HTML stands for HyperText Markup Language. It is the standard language 
used to create and structure web pages.

importance of html:-

Structures content: Defines headings, paragraphs, images, forms, tables, and more.
Creates web pages: Every website uses HTML as its foundation.
Works in all browsers: Browsers like Chrome, Firefox, Safari, and Edge can read HTML.
Supports links: HTML makes it possible to connect pages through hyperlinks.
Helps accessibility: Proper HTML helps screen readers and assistive technologies understand content.
Improves search engines: Search engines use HTML structure to understand and index web pages.

basic structure of html:-
<!DOCTYPE html>                      # Tells the browser that this is an HTML5 document.
<html>                               # The root element that contains the entire webpage.
<head>                               # Contains information about the page that is not displayed directly on the webpage.
    <title>My Web Page</title>       # page title shown in the browser tab
    <meta charset="UTF-8">           # Specifies the character encoding for the document.
    <link rel=""  href="">
</head>                              # closing head tag
<body>                               #Contains all the visible content shown to users.
    <h1>Welcome</h1>
    <p>This is a paragraph.</p>
</body>
</html>
